# Build WebGL de Unity

Copia aquí el contenido de la carpeta `Build/` exportada por Unity:

```
NovelaCali.loader.js
NovelaCali.data
NovelaCali.framework.js
NovelaCali.wasm
```

Si cambias el nombre o la compresión, actualiza `src/config/unity.js`.
Mientras esta carpeta esté vacía, la sección **Novela** mostrará una pantalla de espera.
